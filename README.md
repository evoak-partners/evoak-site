# evoak-site

The public Evoak Partners website — a single static page.

## Files
- `index.html` — the whole site (self-contained; styles are inline)
- `trevor-foster.jpeg` — founder photo, referenced by the page

## Deploy
Hosted on Netlify, deployed from this repo. No build step — Netlify serves these files as-is (publish directory = repo root).

## Source of truth
This repo is the **publish copy only**. The site is authored and maintained in the private `evoak-brain` repo at `practice/gtm/Evoak_Homepage_v2.html`. Edit there, then copy the updated file here as `index.html` and push. Keep the brain private — it never belongs in this public repo.
